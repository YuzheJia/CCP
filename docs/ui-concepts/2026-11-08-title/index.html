Borrowed Light · 封面方案稿 · 2026-11-08

封面：留住分割的灯塔，把她放进去

要改，但不用推倒。现在的封面是整个游戏里最早做的一屏，早于外卖员的故事、对话框和订单票据。左右两个时代共用一座塔，这是全游戏最好的一张图，应该留下；要改的是压在它上面的东西。

  1. 没有主角。游戏里已经有梅的立绘和新小人，封面上一个人都没有。
  2. 文案过时。“Borrow a power cell…” 是改成“送灯芯”之前的说法。
  3. 两套字。标题是细线条的制图字，而对话框、订单票据都是像素字加黄色投影。封面应该和它们是一家人。
  4. 没有菜单。只有 “Press Enter to begin” 和 “按 I 看说明”。存档、声音、说明，玩家只能靠猜。

现在 NOW

方案 A · 分割的灯塔，她站在缝上 推荐

点画面后 W / S 换选项
  1. Logo 换成像素字，和对话框、票据同一套。BORROWED 是过去的暖米色配她的黄色投影；LIGHT 是现在的冷灰配石板色投影，灯还没亮。
  2. 两行副标题各站一边：PICK UP IN THE PAST / DELIVER TO THE PRESENT。它替掉了左上、右上的 PAST / PRESENT，同时把玩法和故事都讲了。
  3. 梅站在塔门口，正好压在两个时代的分界线上：左半身被夕阳照着，右半身在雨里。背影，看得见保温箱。用的就是游戏里的走路小人。
  4. 菜单在左下角的海面上，一列字，W/S 选、Enter 确定。选中项是对话框名牌的样子（墨底、米白字、黄色投影），旁边是对话箭头。
  5. 有存档时，右下角贴一张小订单，就是订单界面那张票的缩小版：继续会进哪一单、下一站是哪一关。选中 CONTINUE 时它也抬起来，带黄色投影。
  6. 送达之后封面会变：“现在”那一半雨停了，天快亮，有星星，灯亮了，光束扫向右边；LIGHT 变暖，副标题变成 DELIVERED TO THE PRESENT，梅转过身来。灯室里有一个很小的人影，是守塔人，只在通关后出现，所以不剧透。

方案 B · 立绘加接单卡片 备选

点画面后 W / S 换选项
  1. 整张画面都是“现在”的雨夜，塔很远、很小，灯是灭的；地平线上只剩一线旧夕阳，是够不着的过去。
  2. 梅的像素立绘占右边一大块，看着远处的塔。就是对话框里那张，放大 4 倍，稍微压暗一点融进夜色。
  3. 菜单是一张外卖 App 的“新订单”卡片：1× 灯芯，取货：过去，送达：现在，地址：灯塔顶层。ACCEPT ORDER 就是开始游戏。卡片外框就是对话框的样子。
  4. 代价：分割的塔这张最有辨识度的图没了；接单卡片和存档界面的订单票也有点重复。

我的建议

选 A。分割的灯塔就是这个游戏的玩法（一个键切两个时代），封面一眼就讲清楚。A 只是在原图上加人、换字、加菜单，Title.hs 里的天空、海和塔都不用动，风险小；“送达之后封面会变”花得很少，回报感很足。B 的接单文案可以借给 A，比如首次打开时 NEW ORDER 后面那行小字。

壁纸：A 去掉菜单就是一张 16:10 的图，可以另外导出 1920×1200 当桌面壁纸；itch.io 封面要 16:9 的话，需要重新构图一次。

  • A 还是 B，或者 A 加 B 的接单文案。
  • Logo 用像素字（稿里这样），还是保留现在的线条字。
  • 通关后灯室里的守塔人人影，要不要。
  • 菜单里要不要 QUIT：全屏启动时有用，窗口模式可以省掉。
