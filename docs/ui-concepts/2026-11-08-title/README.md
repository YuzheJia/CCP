## 两个方案

- **A · 分割的灯塔，她站在缝上**：保留现在的天空、海和塔；Logo 换成像素字（BORROWED 暖色配黄色投影，LIGHT 冷色，送达后变暖）；两行副标题 PICK UP IN THE PAST / DELIVER TO THE PRESENT；梅（游戏里的走路小人，1.35 倍）站在塔门口的分界线上；左下角一列菜单；有存档时右下角贴一张小订单；送达之后“现在”那一半雨停、灯亮、有星星，灯室里有守塔人的小人影。
- **B · 立绘加接单卡片**：整张是“现在”的雨夜，远处一座灭了灯的小塔；梅的像素立绘（对话框那张，4 倍）在右边；菜单是外卖 App 的“新订单”卡片，ACCEPT ORDER 就是开始。

## 怎么画的

`title-core.js` 是 `docs/ui-mockups/save-screen/save-screen.js` 前 541 行原样复制（字体、标题画、订单票零件、立绘）；人物来自 `sprites.js`（`../2026-11-08-characters/sprites.js` 的副本，那个文件夹没有提交）；新东西都在 `title-mockups.js`，坐标是游戏的 1280×800 画布单位，原点在中心、y 向上，可以照着搬进 `app/Title.hs`。

PNG 用无头 Edge 渲染：打开 `index.html?shot=A1`（或 `now`、`A2`、`A3`、`B1`、`B2`），窗口 1280×800。
