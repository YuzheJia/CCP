存档界面：Mei 的运单

每个存档做成 Mei 手里的一张外卖运单小票：送到第几站、路上花了多久、什么时候存的，一张小票全写清楚。画面都按游戏真实的 1280×800 画布画的，用的是游戏里现有的像素字体、笔画字体、标题画、对话框和 Mei 的立绘，没有新素材。方案 A 可以直接用键盘试玩。

从这些游戏里借了什么

好的存档界面都在回答同一组问题：哪个是我的、我上次到哪了、花了多久、要不要开新档、删档会不会误删。下面是每个参考的做法，以及它在本作里变成了什么。

游戏它怎么做用在这里
Hollow Knight每个存档槽直接显示所在区域、完成度和游戏时长，不用点进去就认得出自己的档。每张运单写出下一站的房间名、一条路线进度条、路上时间。
Celeste存档是一张张卡片，选中的那张被抽出来；卡片上是有温度的数字（草莓、死亡次数）。选中的运单抬起来、投出黄色阴影；记“时空切换次数”这种只有本作才有的数字。
Persona 5菜单本身就是世界观的一部分，风格很强，但信息层级依然清楚。小票、胶带、红章、条码都是 Mei 世界里的真东西，不是通用面板。
Destiny 2 等危险操作要长按一段时间才生效，手滑不会误删。删档 = 按住 Enter 沿撕线把运单撕掉。和开场动画“长按跳过”是同一个手势，玩家已经学过。
主机游戏自动存档保存时在角落给一个不打断操作的小提示。通关回到关卡大厅时，右上角吐出一张“ORDER 1 SAVED”小票，几秒后收回。

方案 A · 外卖运单推荐

标题画面按 Enter 后，三张运单贴在变暗的灯塔画面上。小票是热敏打印纸，所以用像素字体；界面外框（标题、按键）沿用站内铭牌的笔画字体，和关卡大厅一致。

点一下画面后可用键盘试玩：AD 或方向键选择，Enter 继续或开新运单，Delete 取消运单（再按住 Enter 撕掉），Esc 返回。

    方案 B · 守塔人日志备选

    保留整张标题画，三块黄铜铭牌放在海面上。灯塔本身显示选中存档的进度：每通关一个房间亮一扇窗，送达后现在这一半的灯也亮起来；光束转过去照着选中的铭牌。AD 可以切换看效果。

    好在哪

    • 从标题画面过来几乎无缝，氛围最强。
    • “灯塔亮了几扇窗”这个进度，眯着眼都看得懂。
    • 光束当选择光标，很有记忆点。

    差在哪

    • 铭牌空间小，只放得下 3 行字，信息比 A 少。
    • 跟 Mei 送货的故事没关系，像是另一个游戏的菜单。
    • 灯塔只能同时显示一个存档的进度，三档对比要来回切。

    在游戏里怎么走

    TITLE · ENTER
    • 还没有任何存档：不进运单界面，直接开 ORDER 1 → 开场动画 → 第 1 关。第一次玩不多一道门。
    • 已有存档：进入运单界面，光标默认停在上次玩的那张，连按两下 Enter 就能接着玩。
    YOUR ORDERS
    • 已有运单 + Enter → 关卡大厅（和现在一样）。
    • 空运单 + Enter → 打印新运单 → 开场动画 → 第 1 关。
    • Delete → Mei 说明后果 → 按住 Enter 撕掉；松手就停，Esc 保留。
    • Esc → 标题画面。
    LEVEL HALL · ESC
    • 回到运单界面（现在是回标题）。左上角标着这是哪张运单。

    审核通过后要改的地方

    • 存档文件升级成 v2，三个槽。现在的 progress-v1.save 第一次启动时自动变成 ORDER 1，进度不丢。
    • 已有的数据：通关了几间、上次选的关。新记三项：路上时间（在关卡和大厅里累计）、时空切换次数、保存时刻。
    • 房间里的进度照旧不存，副标题和大厅底部直接写明“每通关一个房间保存一次”，不让玩家误以为中途退出也能接着来。
    • Game/Run.hs 加一个运单模式，app/ 下新增一个文件画它，Main.hs 加 Delete / Backspace 键，音效加“打印”和“撕纸”（可用对话框的打字音改）。
    • 写盘失败时小票变红写“COULD NOT SAVE”，不假装存好了（见上方“保存失败”）。

    需要你定的

    1. 用 A 还是 B？也可以 A 的运单 + B 的“灯塔亮窗”放进运单界面背景里。
    2. 三个存档槽够吗？游戏三分钟一轮，三个够给朋友各开一档；两个会更简洁。
    3. 小票上的第二个数字记什么？现在是“时空切换次数”（本作独有），也可以换成“重开次数”（像 Celeste 的死亡数）。
    4. 找到隐藏关后，运单上写不写它的名字？现在只写“+ HIDDEN STOP FOUND”，不剧透关名。
